# Scientific validation results

Validation category: **verification** (report-governance index)

Comparative, empirical, calibration, and blind-validation reports belong here.
Each report must be backed by an indexed result manifest under
`data/validation/results/`; the registry command rejects a report without that
lineage.

The current component-resolved Annex 71 object-engine measurement is the
[v4 runtime and error diagnostic](annex71_physical_runtime_error_v4.md). Earlier
post-unsealing iterations are retained under `docs/validation/history/` as
audit history and are not current scientific result entries.
