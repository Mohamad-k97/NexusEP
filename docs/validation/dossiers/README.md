# Phase 4 validation dossiers

Validation category: **verification and validation status reporting**.

Each domain report uses the same required headings: model version and commit,
dataset/license, scenario mapping, preprocessing, calibrated parameters,
untouched validation period, metrics and plots, residual analysis,
limitations, pass/fail decision, and reproducible command. `pass` applies only
to the stated evidence category and scope. `open` or `blocked` is not silently
converted to a pass through a loosely matched alternative.

The source baseline is commit
`63936cc50fe83850d5c9bd1d1b49026f47d91c9f` plus the explicitly dirty Phase
4 working tree. A publication commit must replace that dirty-state marker in
released dossiers.
